# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

## In short

- **Be respectful and welcoming.** That applies to everyone, whatever their experience, background, identity or language.
- **Give constructive feedback.** Critique ideas and code, not people.
- **No harassment, insults, sexualised language, or publishing others' private information.**
- **Assume good faith, and help newcomers.** Many contributors are integrating M-Pesa for the first time.

## Scope

It applies in all project spaces (issues, pull requests, discussions), and when you represent the project elsewhere.

## Reporting

Report unacceptable behaviour privately to the maintainer, [@Mr-Macharia](https://github.com/Mr-Macharia), via GitHub. Reports are handled confidentially.

Consequences follow the Contributor Covenant's enforcement guidelines: correction, warning, temporary ban or permanent ban.
