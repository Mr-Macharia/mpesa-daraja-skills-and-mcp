# mpesa-daraja-mcp → mpesa-daraja

This package was renamed **[mpesa-daraja](https://pypi.org/project/mpesa-daraja/)** in 0.1.5. Installing `mpesa-daraja-mcp` installs `mpesa-daraja` and keeps the `mpesa-daraja-mcp` command, so existing agent configs keep working.

New installs: `uv tool install mpesa-daraja`, then `mpesa init`.
